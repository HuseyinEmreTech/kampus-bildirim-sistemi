- Oturumun telefonda şifreli saklanması: `flutter_secure_storage` onayı bekleniyor; şimdilik `SessionStore` arayüzü var.
- 401 sonrası token yenileme: API dokümanında yenileme ucu yok, sunucu tarafı (#19) yapılmadı.
- Girişi uygulama açılışına (`main.dart`) bağlamak: bu dosya CODEOWNERS'ta web sahibinin onayını da istiyor; gerçek sunucu bağlantısıyla birlikte yapılacak.
- Giriş için GitHub issue'su yok; Hüseyin'den istendi.

  - `ChangeNotifier`: `notifyListeners()` çağrılınca dinleyen ekranlar yeniden çiziliyor; testte `addListener` ile kaç kez haber verildiği sayıldı.
  - Arayüz (`SessionStore`): paket gelmeden kod ve test yazılabiliyor; paket gelince yalnızca gerçek sınıf eklenecek.
  - CODEOWNERS'ta GitHub son eşleşen satırı kullanıyor; `lib/main.dart` genel satıra düştüğü için iki sahibin onayını istiyor.
  - Emin olmadığım: `flutter_secure_storage` web'de nasıl saklıyor, denemedim.
