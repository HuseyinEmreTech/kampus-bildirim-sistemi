## Ne yaptım

- Geliştirme ortamını sıfırdan kurdum: Git, Python 3.11, Docker Desktop (WSL ile), VS Code. Repoyu klonladım, `test/e2e-testleri` branch'ini açtım.
- Sunucuyu `compose.prod.yaml` ile ayağa kaldırdım, demo verisini (`db/seed/001_ornek.sql`) yükledim; `/health` `OK` döndü.
- `test/e2e/` altında Python (pytest + requests) E2E test iskeletini yazdım: giriş yardımcıları, sahte 1x1 PNG, yetki testleri ve bildirim akışı testi (aç, üstlen, 409, çöz, öğrenciye haber).
- Demo veriyi Python ile yükleyen betik (`test/veri/seed_yukle.py`) ve sunucu kapalıyken testleri atlayan `conftest.py` hazırladım.
- Test rehberini (`ekip/test-rehberi.md`) yazdım.

## Ne yapamadım ve neden

- Bildirim akışı testlerini çalıştıramadım: canlı sunucuda `GET/POST /api/reports` ve `GET /api/me/reports` `404 Route not found` dönüyor. Kod aramasında `packages/server` altında bu route yok; `main` (a6112fd) henüz içermiyor. Üç testi `xfail` ile işaretledim.
- Web (Playwright) ve mobil E2E başlanmadı: web istemcisi ve ekranlar henüz hazır değil.
- CI'a Python işi eklenmedi: `.github/` Hüseyin'in alanı, onay bekliyor.
